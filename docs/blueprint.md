# **App Name**: guzelbahce cilingir

## Core Features:

- Dynamic Service Location Pages: Automatically generate dedicated, server-side rendered pages for each neighborhood (e.g., /cilingir/yelki), optimized for local search results, as outlined by Next.js App Router patterns.
- SEO Metadata Management: Utilize Next.js Metadata API to dynamically generate unique titles, descriptions, and keywords for each service location page, tailored to search engine optimization.
- Floating Click-to-Call Button: Implement a persistent, mobile-only 'Call to Action' component (tel:05518901979) fixed at the bottom of the screen, ensuring immediate contact during emergencies.
- Integrated Google Maps Location: Display an embedded Google Maps iframe showing the business's address at the bottom of pages, improving local SEO and user trust.
- Dynamic Service Offerings Display: Render specific service lists and headings (e.g., 'Oto Çilingir', 'Kilit Değişimi') relevant to the user's search query and corresponding ad groups, enhancing ad relevance and user experience.
- Trust Badges Section: Prominently display visual trust badges such as 'Garantili Kilit', 'Resmi İşletme', and '7/24 Hizmet' to build credibility and confidence with visitors.
- JSON-LD Structured Data Implementation: Integrate LocalBusiness schema (JSON-LD) for enhanced search engine visibility, allowing for rich snippets like telephone numbers and ratings in Google search results.

## Style Guidelines:

- Primary color: Professional, deep blue (#2257C3), reflecting reliability and trust, anchoring the design with a modern, authoritative feel.
- Background color: Clean, very light grey-blue (#F0F3F8) as the main background, providing a subtle foundation that highlights content without distraction.
- Accent color: Vibrant and refreshing turquoise (#17CDED) to draw attention to call-to-actions and important interactive elements, suggesting speed and clarity.
- Headline and body text font: 'Inter' (sans-serif), chosen for its clear, modern, and highly legible appearance, ensuring professionalism across all content, critical for emergency services.
- Utilize clean, modern line icons for service categories and trust badges, enhancing visual clarity and quick comprehension during emergencies.
- Mobile-first, responsive layout prioritizing content readability and immediate action. Implement a clear content hierarchy with prominent H1 titles and dedicated service sections for rapid information retrieval, adhering to a minimum Lighthouse score of 90+.
- Subtle, smooth transition animations for navigation and element reveals, providing a polished user experience without hindering page speed or urgent interactions, aligning with the app's fast-service nature.
